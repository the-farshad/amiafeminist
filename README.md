# ئایا تۆ فێمینیستی؟ — Am I a Feminist? (Kurdish)

A Kurdish (Sorani) translation of the interactive **"Am I a Feminist?"** quiz,
a short set of questions that helps you reflect on whether your values align
with feminism.

**Live:** <https://amiafeminist.thefarshad.com>

This is a fork of [jadijadi/amiafeminist](https://github.com/jadijadi/amiafeminist),
translated into Kurdish and hosted on GitHub Pages.

## Running locally

It's a static site — no build step. Serve the folder with any static server:

```sh
python3 -m http.server
```

Then open <http://localhost:8000>.
